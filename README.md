## English (summary)
A single-file, analytics-focused **personal habit tracker**. Bilingual (Ukrainian / English), light & dark themes, mobile-first. Daily check-off, consistency score, streaks, month calendar with backfill, full-year heatmap, weekly grid, and analytics (overall completion, 7-day trend, weekly bars, habit ranking, correlations).
Data is stored **locally in your browser** (localStorage) — nothing is sent anywhere. Back up and restore via **Export / Import** (`.json`) in Settings.
Deploy by placing `index.html` at the repo root and enabling **GitHub Pages** (branch `main`, `/root`). No build step, no dependencies.
